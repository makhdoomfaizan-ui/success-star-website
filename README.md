# Success Star Training Center Website

Modern Next.js website for Success Star Training Center (Sharjah, UAE).

## Commands

```bash
npm install
npm run dev
npm run build
```

Open [http://localhost:3000](http://localhost:3000).

## Content files

- `src/content/courses.ts` — courses + SEO keywords
- `src/content/blog.ts` — blog posts
- `src/content/faculty.ts` — faculty profiles
- `src/content/gallery.ts` — gallery images
- `src/lib/site.ts` — phone, address, WhatsApp, brand text
